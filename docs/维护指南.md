# 维护指南 · 怎么改 Slicelog

这份文档写给「接手后要动代码的人或 AI」。看完这一页，不需要先通读 5000 行 HTML 就能上手改。
界面是中文，代码注释也是中文，**保持这个风格**。

> 当前版本 **V1.0**：`index.html` 里 `.sf-ver` 显示 `V1.0`，`app/build.gradle` 的 `versionName` 同为 `1.0`（`versionCode 33`）。

## 1. 五分钟上手

```bash
# 编译安卓调试包（本机路径，换机器改用 ./gradlew assembleDebug）
JAVA_HOME=/d/APP/AndroidBuild/jdk/jdk-17.0.2 \
ANDROID_HOME=/d/APP/AndroidBuild/sdk \
/d/APP/AndroidBuild/gradle/gradle-8.9/bin/gradle assembleDebug --offline

# 浏览器里预览（不装手机也能改界面）
cd tests && node serve.cjs      # http://127.0.0.1:8770/app

# iOS / PWA 预览
cd ../ios && node tools/serve.cjs   # http://127.0.0.1:8773/
```

改完跑回归：`node tests/v215-check.cjs`（设置面板与提醒移除）、`node tests/v212-check.cjs`、`node tests/smoke.cjs`、`node tests/fit.cjs`。
iOS 侧：`cd ios && node tools/iphone-check.cjs`。

## 2. 文件地图

| 想改什么 | 去哪个文件 | 说明 |
|---|---|---|
| 界面、交互、样式、图表 | `app/src/main/assets/index.html` | **99% 的改动都在这里**。HTML + CSS + 原生 JS 一个文件，约 5200 行 |
| 系统能力（分享、导出、安全区） | `app/src/main/java/com/growthos/journal/MainActivity.java` | 唯一 Activity，桥接方法都在 `AndroidBridge` 内部类 |
| 权限、入口 | `app/src/main/AndroidManifest.xml` | 当前**权限为空**，只有 Activity + 导入 json 的 intent-filter |
| 版本号 | `app/build.gradle` + `index.html` 的 `.sf-ver` | 两处，见第 4 节 |
| 主题、图标、启动图 | `app/src/main/res/**`、`app/src/main/assets/brand/*.png` | logo 在网页里是 base64 内嵌，换图要两处一起换 |
| iOS / PWA | `ios/index.html`（由安卓版复制而来）+ 适配层 | 见第 6 节 |

`index.html` 内部大致顺序：head（主题预加载 / 安全区 / iOS 适配层）→ `<style>` → 布局骨架 → 全部逻辑 `<script>`。
逻辑里几个关键锚点（搜函数名就能跳过去）：

| 名称 | 作用 |
|---|---|
| `STORAGE_KEY = 'growth-os-v1'` | localStorage 单键，改名字会导致老数据读不到 |
| `seedState()` | 「示例数据」，首次打开与测试截图都用它 |
| `normalizeState(raw)` | **老数据迁移**：新增字段必须在这里兜底 |
| `saveState()` | 保存 + 自动快照 |
| `THEMES` / `applyTheme()` | 五套配色 |
| `VIEW_META` / `VIEW_ORDER` / `switchView()` / `render()` | 视图注册与分发 |
| `renderDashboard / renderGoals / renderHabits / renderJournal / renderFinance / renderDetail` | 各视图渲染 |
| `donutChart()` | 环形图（月度支出构成、年度支出构成共用） |
| `openMonthPicker()` | 记账页的 12 格月份面板 |
| `openModal()` / `askConfirm()` / `toast()` | 弹窗、二次确认、轻提示 |

## 3. 常见改动配方

### 3.1 改文案
全局搜中文原句直接替换。注意三处容易漏：
- `VIEW_META` 里每个视图的 `title` / `sub`
- `index.html` 的 `<title>` 与 `ios/index.html` 的同名标签
- `AndroidManifest.xml` 的 `android:label`、`res/values/strings.xml`

### 3.2 改配色 / 加一套主题
1. 在 `THEMES` 数组加一项（`id / name / desc / dark / bg / card / line / accent`）
2. 在 `<style>` 里照抄 `[data-theme="oat"] { ... }` 整段，改 id 与色值（每套只有 1 个强调色 + 3 级中性色）
3. 顶部主题预加载脚本里的 `_themes` 数组加上新 id
4. 跑 `node tests/v215-check.cjs` 和 `node tests/theme-audit.cjs`，对比度低于 4.5:1 会被拦下

### 3.3 加一个视图（页面）
1. `VIEW_META` 加 `{ title, sub }`
2. `VIEW_ORDER` 决定左右滑动顺序，`#nav` 里加一个 `<button data-action="nav" data-view="xxx">`
3. 写 `renderXxx()`，并在 `render()` 的 `renderers` 表里登记
4. 骨架 `<section id="view-xxx" class="view">` 照现有视图复制

### 3.4 给数据加字段
1. `normalizeState()` 里加兜底（老数据没有这个字段时给默认值）
2. `seedState()` 里给示例数据也补上
3. 表单里加控件，保存时写进 `state.xxx`
4. 改了结构就顺手写一条回归断言，防止以后被改坏

### 3.5 改设置面板
设置面板是 `.sidebar-foot` 里的三个 `.sf-group`（备份 / 外观 / 危险区），按钮统一用 `data-ico` 挂图标。
加按钮：塞进对应 `.sf-group`；要整行就加 `sf-wide`；点了要干活就在 `document` 的 click 委托里加 `data-action` 分支。
面板底部 `.sf-ver` 是版本号。

### 3.6 换 logo / 图标（三处必须同步）
1. `app/src/main/assets/brand/mark-640.png`（启动封面）
2. `brand/mark-tight-128.png`（顶栏 40px / 侧栏 44px）
3. `res/drawable-xxxhdpi/ic_launcher_mark.png`（桌面图标前景）

网页里的两处 logo 是 **base64 内嵌**进 `index.html` 的（避免 WebView 读不到 `file:///android_asset/` 子资源导致裂图），所以换图必须重新生成 base64 再替换。
iOS 图标：`ios/tools/icon-src.html` 内嵌同一张徽章 → `cd ios && node tools/icon-gen.cjs` 生成全套尺寸。

### 3.7 改图表
环形图统一走 `donutChart(items, opts)`，返回 SVG 字符串；不要用 `height:100%` 撑容器（WebView 里会塌成 0），用固定像素或 `viewBox`。

### 3.8 版本号怎么发
改两处：`app/build.gradle` 的 `versionName` + `index.html` 里 `.sf-ver` 的 `V1.0` 文案。
`versionCode` 必须**单调递增**（当前 34），否则装不上覆盖包。

### 3.9 抄「倒数日」这种列表（日记页那块）
倒数日是最小的一块完整功能，想加同类「卡片列表 + 手动排序」的东西，照抄这六步：

1. 数据：`state.countdowns` 数组，**数组顺序就是展示顺序**，不要额外加 `order` 字段
2. 清洗：`normalizeState()` 里过滤脏数据（标题空、日期非 `YYYY-MM-DD` 的直接丢掉）
3. 渲染：`countdownCardHTML()` → 外面套 `foldCard('journal:countdown', ...)`，里面的 `countdownItemHTML()` 出单条
4. 天数：`cdDiff(dateStr)` 用 `Date.UTC` 只比年月日，别用毫秒差（有夏令时和时分误差）
5. 交互：`data-action` 走 click 委托四件套 `add / edit / del / move`；排序就是数组里 `[a,b] = [b,a]`
6. 回归：`tests/v217-check.cjs` 覆盖了天数口径、增删改、排序、深色主题、持久化、空态

排序按钮的 `disabled` 不要配 `pointer-events:none` —— 禁用的按钮本身就不派发 click，加了反而会让点击穿透到卡片上误开编辑。

## 4. 数据与迁移

- 单键 `localStorage['growth-os-v1']`，结构 `{ settings, habits, goals, finance, journal, countdowns, ... }`
- 读到老数据先过 `normalizeState()`：缺字段补默认、非法值纠正、旧类型转换（例如旧「学习」项目并进目标）
- 每次 `saveState()` 会顺手 `autoSnapshot()`：应用私有目录按天留 8 份；iOS 版没有文件系统，退化为 localStorage 留 5 份
- **删功能不要删字段**：字段留在 `normalizeState` 里当读入兼容，界面不再展示即可（例如目标的 `dueTime` 现在只当截止时刻用）

## 6. 两端同步（重要）

iOS 版**不是**独立实现，而是「同一份 `index.html` + 一段 PWA 适配层」：

```
ios/index.html = 安卓版 index.html
               + iOS 专属 meta（apple-*、manifest、touch-icon）与 viewport 的 maximum-scale=1
               + 一段脚本把 AndroidBridge 用 Web API 补出来（分享 / 导出 / 自动存档 / 主题色）
               + iOS 专属 CSS（输入框 16px、standalone 全屏、添加到主屏幕提示条）
               + Service Worker 注册
```

所以**安卓版改完界面，iOS 要重新同步**：

1. `cp app/src/main/assets/index.html ios/index.html`
2. 补回 head 里那批 iOS meta（对比 `git diff` 上一次同步的提交最省事）
3. 补回适配层脚本（`window.AndroidBridge = { setSystemBars, exportBackup, shareBackup, autoBackup, readAutoBackup, openAppSettings, getScreenInfo }`）与 `</style>` 前的 iOS CSS
4. `cd ios && node tools/iphone-check.cjs` 验证 8 项
5. 如果改了品牌/外观，`node tools/icon-gen.cjs` 重出图标，`node tools/build-dist.cjs` 重出 `dist/`

**不要**在 iOS 版里单独修 bug —— 会是两份分叉的代码。永远以安卓版为准，再同步过去。

## 7. 踩过的坑（改之前先看一眼）

1. **WebView 百分比高度塌成 0**：容器高度用固定 px 或 SVG `viewBox`，别指望 `height:100%`
2. **原生日期框点不开**：隐藏了 `::-webkit-calendar-picker-indicator` 后必须用 `showPicker()`，并加 700ms 防抖；`::-webkit-datetime-edit-*` 要逐段写颜色，否则深色下是白底
3. **零依赖是硬约束**：不引第三方库、CDN、网络字体。`AndroidManifest.xml` 里连 INTERNET 权限都没有
4. **权限必须保持为空**：`aapt2 dump permissions` 应为空。v2.15 起通知/闹钟/前台服务全删了，别加回来（README「已知限制」写了原因）
5. **`.sidebar-foot` 手机端是浮层**：媒体查询里 `flex-direction` 必须是 `column`，否则分组只有内容宽、`sf-wide` 铺不满
6. **主题色变量只认 `--xxx` 令牌**：硬编码颜色在深色主题下会翻车，跑 `theme-audit.cjs` 能查出来
7. **中文批量改文件**：Python 容易把中文写成 `\uXXXX` 转义，改完 grep 一眼
8. **Android 桥接在网页里不存在**：所有调用都要 `if (window.AndroidBridge && typeof xxx === 'function')` 兜底，否则桌面预览直接报错
9. **tag 与构建号**：`versionName` 是展示版本（`1.0`），`versionCode` 是覆盖安装的依据，两者别混
